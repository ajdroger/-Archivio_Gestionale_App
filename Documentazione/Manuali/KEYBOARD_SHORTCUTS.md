# ⌨️ KEYBOARD SHORTCUTS MCAG
## Scorciatoie Tastiera

**Versione**: 1.0
**Data**: 27 Gennaio 2026

---

## GLOBALI

| Shortcut | Azione |
|----------|--------|
| `Ctrl+K` | Quick search (ricerca globale) |
| `Ctrl+/` | Toggle sidebar |
| `/` | Focus search bar |
| `Esc` | Chiudi modal/dropdown |
| `?` | Mostra shortcuts helper |

---

## NAVIGAZIONE

| Shortcut | Destinazione |
|----------|--------------|
| `G` → `D` | Go to Dashboard |
| `G` → `S` | Go to Soci (Anagrafica) |
| `G` → `W` | Go to Workshift |
| `G` → `T` | Go to Settings |
| `Ctrl+H` | Home (Dashboard) |

---

## AZIONI

| Shortcut | Azione |
|----------|--------|
| `Ctrl+N` | Nuovo Socio |
| `Ctrl+S` | Salva form corrente |
| `Ctrl+E` | Modifica record corrente |
| `Ctrl+Del` | Elimina record selezionato (con confirm) |
| `Ctrl+P` | Stampa/Export PDF |

---

##  TABELLE

| Shortcut | Azione |
|----------|--------|
| `↑` `↓` | Naviga righe |
| `Enter` | Apri dettaglio riga selezionata |
| `Space` | Seleziona/Deseleziona checkbox |
| `Ctrl+A` | Seleziona tutti |
| `Ctrl+Shift+A` | Deseleziona tutti |

## MODALI & FORM

| Shortcut | Azione |
|----------|--------|
| `Tab` | Next field |
| `Shift+Tab` | Previous field |
| `Ctrl+Enter` | Submit form (alternativa a click Salva) |
| `Esc` | Chiudi modal senza salvare |

---

## DEVELOPER (DevTools Mode)

| Shortcut | Azione |
|----------|--------|
| `Ctrl+Shift+D` | Toggle DevTools panel |
| `Ctrl+Shift+L` | View logs (last 100) |
| `Ctrl+Shift+C` | Clear cache |
| `Ctrl+Shift+R` | Reload senza cache |

---

## MAC (Sostituzioni)

Su macOS, sostituisci:
- `Ctrl` → `Cmd` (⌘)
- `Alt` → `Option` (⌥)

Esempio: `Cmd+K` invece di `Ctrl+K`

---

## PERSONALIZZAZIONE

**Admin**: Vai Settings → Shortcuts → Personalizza  
**Utente**: Preferenze Profilo → Keyboard
