# 📖 GLOSSARIO MCAG
## Termini e Acronimi

**Versione**: 1.0
**Data**: 27 Gennaio 2026

---

## A

**AI** - Artificial Intelligence. MCAG usa AI per Workshift optimizer e RAG assistant.

**API** - Application Programming Interface. MCAG espone REST API per integrazioni.

**APM** - Application Performance Monitoring. Tool per tracciare performance (Sentry).

**Audit Log** - Registro cronologico di tutte le azioni utenti (chi, cosa, quando).

**AES-256-GCM** - Advanced Encryption Standard con Galois/Counter Mode. Encryption algorithm usato per Document Vault.

---

## B

**Backup** - Copia dati di sicurezza. MCAG fa backup automatici daily.

**Bug** - Errore software. Report via GitHub Issues.

**BEM** - Block Element Modifier. Metodologia naming CSS usata in MCAG.

---

## C

**CI/CD** - Continuous Integration/Continuous Deployment. Pipeline automatica build→test→deploy.

**CSRF** - Cross-Site Request Forgery. Attacco web bloccato da CSRF token.

**CRUD** - Create, Read, Update, Delete. Operazioni base database.

**CSV** - Comma-Separated Values. Formato export dati.

---

## D

**Dashboard** - Pannello principale con overview metriche sistema.

**DevTools** - Pannello debugging per developer (Hyper-Grid Console).

**DRP** - Disaster Recovery Plan. Piano recupero da disastro catastrofico.

**DTO** - Data Transfer Object. Pattern architetturale per trasporto dati between layers.

---

## E

**ELK** - Elasticsearch + Logstash + Kibana. Stack centralizzato logging.

**Encryption** - Cifratura dati. MCAG usa AES-256.

---

## F

**Fiscal Code** - Codice Fiscale italiano. MCAG calcola automaticamente.

**Feature** - Funzionalità software. Request via GitHub Discussions.

---

## G

**GDPR** - General Data Protection Regulation. Regolamento UE privacy. MCAG è compliant.

**Git** - Version control system. MCAG usa Gitflow workflow.

**God Mode** - Emergency access protocol per CEO senza password.

---

## H

**HAProxy** - High Availability Proxy. Load balancer usato per horizontal scaling.

**Healthcheck** - Endpoint `/health` verificato dai load balancers.

---

## I

**ICP** - Ideal Customer Profile. Target cliente perfetto per MCAG.

**Integration** - Connessione con sistemi esterni via API.

---

## J

**JWT** - JSON Web Token. Standard authentication token.

---

## K

**KPI** - Key Performance  Indicator. Metriche business critiche (es. revenue, NPS).

---

## L

**Matricola** - Codice univoco socio (es. SOC-00001).

**Middleware** - Software layer tra request e controller (es. AuthMiddleware).

**Migration** - Processo spostamento dati da sistema legacy a MCAG.

---

## N

**NDA** - Non-Disclosure Agreement. Contratto riservatezza.

**NPS** - Net Promoter Score. Metrica customer satisfaction (-100 a +100).

---

## O

**OEM** - Original Equipment Manufacturer. Tipo licenza per embed MCAG in altro prodotto.

**On-Premise** - Installazione su server proprietario cliente (vs cloud).

---

## P

**PITR** - Point-In-Time Recovery. Ripristino database a timestamp specifico.

**PSR-12** - PHP Standards Recommendation 12. Coding standards utilizzato.

---

## Q

**Queue** - Coda asincrona per task pesanti (email, PDF gen, export).

---

## R

**RAG** - Retrieval-Augmented Generation. Tecnica AI per assistente intelligente.

**Redis** - In-memory cache. Usato per session storage e caching.

**REST** - Representational State Transfer. Architettura API MCAG.

**ROI** - Return On Investment. Ritorno investimento (€ guadagnati / € spesi).

**RPO** - Recovery Point Objective. Max perdita dati tollerata (15 min MCAG).

**RTO** - Recovery Time Objective. Tempo max recupero da disastro (4h MCAG).

---

## S

**Socio** - Membro associazione (equiv. "Member" in English).

**SLA** - Service Level Agreement. Garanzia uptime (99.9% MCAG).

**SQLi** - SQL Injection. Attacco  prevenuto da prepared statements.

**SWOT** - Strengths, Weaknesses, Opportunities, Threats. Analisi strategica.

---

## T

**TCO** - Total Cost of Ownership. Costo totale 3-5 anni include licenza + maintenance + implementation.

**TOTP** - Time-based One-Time Password. Algoritmo 2FA (Google Authenticator).

**Turno** - Shift lavorativo dipendente (in Workshift module).

---

## U

**UAT** - User Acceptance Testing. Test finale pre-go-live con utenti reali.

---

## V

**Vault** - Document Vault. Repository sicuro file encrypted.

---

## W

**Workshift Commander** - Modulo gestione turni con AI optimizer.

---

## X

**XSS** - Cross-Site Scripting. Attacco bloccato da output escaping.

---
