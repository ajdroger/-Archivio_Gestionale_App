# Job Description: Junior Full-Stack Developer (PHP/Refactoring Focus)

**Role**: Junior Maintainer & Developer  
**Project**: MCAG (Mission Critical Archivio Gestionale)  
**Location**: Remote / Hybrid (Italy)  
**Type**: Contract / Part-time

## 🚀 The Mission
We are looking for a dedicated Junior Developer to take over the daily maintenance and evolution of **MCAG**, a mission-critical management system built on a modern PHP stack (Slim 4, PHP 8.2+).
You will be working with a high-standard "Clean Architecture" codebase that adheres to strict Enterprise principles (SOLID, ADRs, Security).

## 🛠 Tech Stack You Will Master
*   **Backend**: PHP 8.2+, Slim 4, PHP-DI, Mustache Engine.
*   **Frontend**: Vanilla JS (ES6+), Tailwind CSS, HTMX, Bootstrap 5.
*   **Integrations**: SOAP/REST (Zucchetti), AI (Ollama/OpenAI), PDF generation.
*   **Tools**: Gitflow, Docker, Composer, PHPUnit.

## 📋 Responsibilities
1.  **System Health**: Monitor logs (Sentry/Monolog) and fix reported bugs.
2.  **Refactoring**: Continue the "Ghost Code Elimination" initiative (ADR-050).
3.  **Features**: Implement new modules following strict ADR guidelines.
4.  **DevOps**: Manage Docker containers and Release tagging.

## 🎓 Requirements
*   **Must Have**:
    *   Good knowledge of PHP 8+ and OOP.
    *   Familiarity with MVC patterns.
    *   Git basics (Branching, Merge Conflicts).
    *   Italian & Technical English.
*   **Nice to Have**:
    *   Experience with Legacy Code Refactoring.
    *   Basic Linux/Bash skills.
    *   Knowledge of "Clean Code" principles.

## 🎁 What We Offer
*   **Mentorship**: Direct code reviews from Senior Architects.
*   **Modern Stack**: No "Spaghetti Code" allowed. You work on clean, typed code.
*   **Impact**: Your code runs mission-critical operations.
